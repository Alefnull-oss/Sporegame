# Sporegame

> Mi luz crece

Sporegame es un proyecto de videojuego desarrollado principalmente en Kotlin. Este repositorio está pensado como base para crear una experiencia jugable con enfoque en la exploración, la evolución y la estética visual.

## Descripción general

Este proyecto nace como una idea de juego con identidad propia, donde la narrativa y la mecánica se desarrollan alrededor del crecimiento, la luz y la supervivencia de una entidad o mundo vivo. La estructura está preparada para evolucionar con nuevas mecánicas, niveles, arte, sonido y lógica de juego.

## Tecnologías

- Kotlin
- Gradle
- IntelliJ IDEA / Android Studio (recomendado)
- Git para control de versiones

## Requisitos previos

Antes de comenzar, asegúrate de tener instalado:

- JDK 17 o superior
- Gradle
- IntelliJ IDEA o Android Studio
- Git

## Cómo empezar

1. Clona el repositorio:

```bash
git clone https://github.com/Alefnull-oss/Sporegame.git
cd Sporegame
```

2. Compila el proyecto:

```bash
./gradlew build
```

3. Ejecuta la aplicación o el juego desde tu entorno de desarrollo.
